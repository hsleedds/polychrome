# Polychrome — 결정 사항 명세 (SPEC)

작성 2026-11-25 · HS와의 기획 대화에서 확정된 내용. 모든 작업은 이 문서를 기준으로 한다.
원본 인수인계: `docs/handoff-from-roundcast.md` (1장 매각 대비 원칙은 그대로 유효).

## 0. 원칙
- 별도 저장소(hsleedds/polychrome) · 별도 Supabase(polychrome, 서울, `https://wyeailynedvmxzwffuas.supabase.co`) · 별도 키 · 회원 없음(로그인 없이 시작).
- 날씨 계산은 반드시 `core/weather-core.js`. 천문·촬영 계산은 `core/sky-core.js`(같은 소유, Roundcast에는 안 줌).
- 비밀 키는 Supabase Secrets에만. 브라우저에는 공개 키(Supabase publishable, 카카오 JS, MapTiler)만.
- 공공데이터포털 키는 `KMA_KEY` 하나로 모든 data.go.kr 서비스에 사용.
- 키가 없는 기능은 **기능 스위치(feature flag)로 꺼 둔 채** 만들어 둔다. 스위치는 `app_config` 표 + `app/config.js` 기본값.
- 한국어/영어 동시 지원(문구는 `app/i18n/ko.json`, `en.json`). 브라우저 언어 자동, 「한/EN」 전환. 단위 °C·mm·m/s 기본, 영어/미국 지역은 °F·in·mph 선택.
- 전 세계 지원. 한국이 가장 정밀(기상청 덮어쓰기, ASOS 채점). 시간대는 도시별 IANA 시간대.
- 배포: GitHub Pages (`https://hsleedds.github.io/polychrome/`). 정적 파일, 빌드 도구 없음(바닐라 JS ES 모듈, CDN 라이브러리 허용).
- 출처 표시: 기상청 · Open-Meteo(CC BY 4.0) · MET Norway · 에어코리아(공공누리 3유형: 출처표시·변경금지 → 값을 고치거나 섞지 않음) · NOAA SWPC · USGS 등.

## 1. 날씨 화면
- **사용자별 도시 최대 5곳**(브라우저 localStorage), 그중 1곳 메인(★). 첫 접속 기본: **서울 종로구 1곳**(종로구청 부근 37.5735, 126.9790). 영어도 같은 기본값(Jongno, Seoul).
- **기본 화면(B)**: 한 화면에 한 도시. 좌우로 넘겨 5개 도시. 위쪽 점 표시. 앱을 열면 메인부터. 5개 미만이면 마지막 장 「지역 추가」.
  - 위 1/3: 메인 카드(가장 자세히) — 선 아이콘(큰 것), 현재 기온, 하늘, 체감, 최고/최저, **한 줄 요약**, 비 줄(24시간 비 확률·기관 일치도), 미세먼지, 3시간 간격 기온 띠. 탭하면 전체 상세.
  - 그 아래: **오늘부터 7일 예보** 줄(요일 · 아이콘 · 최저~최고 · **비 확률·강수량을 가장 눈에 띄게**). 줄 탭 → 그날 시간별.
  - 그 아래 카드: 평소 「오늘의 빛」(노을 가능성, 골든/블루아워, 월출·위상·밤 구름). 48시간 안에 비 → **비 카드**가 먼저(시작·그침, 예상 강수량과 범위, 기관 일치도). 오로라 가능성/초미세먼지 나쁨 이상이면 줄 추가.
  - 맨 아래 얇은 메뉴: 날씨 / 출사 / 설정.
- **보조 화면(A)**: 메인 위 1/3 + 나머지 4곳 2×2 칸. 설정 → 화면 구성에서 선택.
- **관리자 모드**: 비밀 주소(`?admin=<토큰>`) → 서버 함수 `admin`이 `ADMIN_TOKEN`과 대조 → 확인된 기기에 표시. 관리자에게만 「내 위치(GPS)」 장(맨 앞)과 적중률 화면. 좌표는 기기에서만 쓰고, 요청 시 소수 3자리 반올림. 위치기반서비스 신고 후 스위치 `gps_public`으로 전체 공개.
- **선 아이콘 세트**(Tabler MIT 기반 + 직접 그림): 해/달(실제 위상)/해+구름/달+구름/구름/안개/이슬비/비(양별)/소나기(낮·밤)/눈/진눈깨비/뇌우/강풍. 낮밤은 그 도시 일출·일몰. 메인 카드만 무지개 포인트 색(해 금빛, 비 파랑, 눈 하늘색, 번개 주황).
- 디자인: Roundcast와 다르게 — 밝은 남색 바탕 + 무지개 포인트, 다크/라이트 자동. 글꼴 Noto Sans KR.
- 한 줄 요약 우선순위: 극한(한파/폭염) → 비 시작·그침 → 초미세먼지 나쁨 → 기온 변화 → 무난.

## 2. 예보 자료
- 기본: Open-Meteo(전 세계, 지역 고해상도 모델 포함) → 4초 지연 시 MET Norway (`omOrMet`).
- 한국: 기상청 동네예보 `kma` 함수(배포 완료·응답 확인됨)로 오늘~글피 덮어쓰기(`kmaOverlay`).
- 기관 비교: 국내(KIM·LDPS·GDPS) + 해외 7. 해외 도시는 「현지 기관」을 맨 위(일본→JMA, 독일→ICON-D2, 프랑스→AROME, 미국→HRRR/NBM, 북유럽→MET Nordic, 영국→UKMO).
- 미세먼지: 한국 에어코리아(서버 함수 `air`: 측정소 목록 하루 1회 캐시 → 가장 가까운 측정소 실시간, 「-」이면 다음 측정소; 예보통보 3시간 캐시), 해외 Open-Meteo 대기질(CAMS, 「추정」 표시).
- 레이더 초단기(0~5시간): 기상청 API허브(`KMA_HUB_KEY`, 스위치 `radar`). 0~5시간은 레이더, 이후 모델 합의.
- 기관별 **발표 시각 표시**, 오래된 기관은 흐리게.

## 3. 정확도: 수집 → 채점 → 가중치 (핵심은 **비 여부와 강수량**)
- **수집(오늘부터)**: 전국 대표 ASOS 관측소 약 30곳 좌표에서
  - 매시간: 기상청 단기·초단기(kma), (레이더 키 생기면 레이더)
  - 3시간마다: Open-Meteo 다중 모델(한 요청에 여러 모델) 72시간 시간별 강수량·강수확률·기온·바람·구름·시정, MET Norway
  - 저장: (기관, 발표/수집 시각, 지점, 대상 시각, 값들). **덮어쓰지 않음.** 리드 = 대상 − 발표.
- **실측(하루 1번)**: ASOS 시간자료(강수량, 기온, 풍속·돌풍, 시정, 전운량, 일조, 적설, 습도). 결측과 무강수 구분(품질 플래그). 「그 시각까지 1시간」 기준으로 정렬(기관별 기준은 첫 자료로 확인).
- **채점(하루 1번)**, 최근 30일, 기관 × 리드 구간(0–5h / 5–24h / **전날 저녁 예보**(전날 17–21시 발표 → 다음날) / 1–2일 / 3일+):
  - 비 여부: 화면과 같은 기준 `isWet`(확률 50%↑ 또는 0.5mm↑); 실측 0.1mm↑. 4칸표(맞힘·놓침·헛예보·정답무강수) → 적중률, 헛예보율, CSI. 1시간·3시간·낮(06–18) 칸 모두.
  - 확률: Brier, 신뢰도(70%라 한 날 실제 비율).
  - 강수량: 비 있었던 칸만 — 평균 오차, 치우침(배율, 보정값으로 사용), 구간 적중(<1, 1–5, 5–10, 10–30, 30+ mm).
  - 시작·그침 시각 오차, 예보 일관성(같은 대상 시각의 뒤집힘 횟수, 실측 불필요), 몇 시간 전부터 맞혔나, 폭우(10·30mm/h) 별도, 비/눈 형태.
  - 2순위 저장·점수표만: 최고·최저기온 오차, 강풍, 시정·안개, 전운량·일조, 미세먼지 예보 등급.
- **가중치**: 비 여부용과 강수량용 **따로**. 기록 부족(2~3주) 동안은 같은 무게 → 충분하면 자동 전환. 가중치는 `weights` 표(익명 읽기 허용).
- **합의 예보** `consensus()`: 비 확률(가중)과 등급(70%↑ 확실, 40%↑ 가능, 그 아래 낮음), 예상 강수량(가중·치우침 보정, 범위), 시작·그침, 기관 일치도.
- 관리자 적중률 화면(지금 만듦, 데이터 쌓이면 채워짐).
- 해외 채점은 지역별로 나중(NOAA 전 세계 관측 등).

## 4. 출사 메뉴
1. **출사 예보**(1순위): 은하수, 운해, 물안개·반영, 무지개, 먼 산 보이는 날(시정), 노을·아침놀. (2순위): 물때(국립해양조사원), 유성우·천문 현상(월식·일식·행성·ISS), 상고대·설경, 드론 비행 조건(고도별 바람·돌풍), 꽃·단풍 시기(적산온도). 카드: 「내일 아침 운해 높음 (용문산·구름 높이 700m)」.
2. **촬영 라인**: 지도에서 대상 점 탭 + 높이 → 해/달, 날짜·시각(시간 막대) → 대상에서 해·달 반대 방향 **띠**(지름 0.5°)와 거리 눈금(꼭대기에 걸리는 지점, 달/대상 크기 비율), 지형 표고로 거리 재계산, 지구 곡률·대기 굴절. 선 위 점 탭 → 거리·방위·고도·위상·그 시각 날씨(지평선 구름·시정·미세먼지·비). **가림 색칠**(초록 보임 / 노랑 일부 가림 / 빨강 가림).
3. **날짜 찾기**: 대상 + 촬영 위치(눈높이) → 12개월(최대 수년) 겹치는 날짜·시각 목록(꼭대기에 걸림/대상 어디든/높이 지정, 보름 전후·박명 필터), 추천 순위(달: 보름+박명, 해: 낮은 고도), 10일 이내 날씨 붙임, 저장(로컬)·.ics 캘린더.
4. **실루엣 미리보기**: 구조물 이름 → 단순 3D 블록 모형(유명 구조물 직접 제작, 없으면 OSM 건물 상자, 사용자 높이·폭) → 촬영 위치에서 본 실루엣(방위각×고도, 실제 각크기) + 해·달 궤적(간격 표시, 실제 지름, 달 위상·기울기) + 지형 지평선 + 렌즈 화각 틀(24–800mm) + 시간 막대. **해·달을 끌어다 놓으면 촬영 위치 이동**.
5. **가상 시야**: 지형(국내 브이월드/국토지리정보원 DEM, 해외 Copernicus 30m) + 건물(국내 브이월드·국토부 건물정보, 해외 OSM·Overture)로 그 지점에서 본 모습 + 가림 판정 문장. 건물 공급원 순서: ①브이월드에서 필요할 때 주변만(캐시) → ②수도권·부산·인천 미리 저장 → ③전국 저장. 공급원 교체해도 화면·계산 코드는 그대로(공급원 인터페이스). 최종 확인은 카카오 로드뷰 버튼.
6. **오로라**: 도시 목록은 날씨 도시와 **별도 저장**, 기본 5곳: 트롬쇠(69.6492, 18.9553), 레이캬비크(64.1466, -21.9426), 로바니에미(66.5039, 25.7294), 옐로나이프(62.4540, -114.3718), 페어뱅크스(64.8378, -147.7164). 첫 장 5곳 요약(현지 시각·판정·최적 시간), 넘기면 상세.
   - **Polychrome 오로라 지수 0~10** = 10 × 오로라 세기 × 맑음 × 어둠(해) × 달.
     - 세기: NOAA OVATION 위치별 확률(또는 북쪽 지평선 가시), 이후 시간은 Kp 예보 환산.
     - 맑음: 1 − 유효 구름(낮·중간 그대로, 높은 구름 절반).
     - 어둠: 해 고도 −6°→0, −18°→1 (선형). 백야·하얀 밤·극야 자동 반영.
     - 달: 위상(밝기) × 고도(지평선 아래 0, 낮으면 작게, 30°↑ 최대) × 방향(남쪽이면 덜). 깎는 최대치는 오로라 세기에 반비례(약하면 최대 90%, 강하면 약 30%).
     - 등급: 0–2 없음, 3–4 낮음, 5–6 기대해 볼 만함, 7–8 높음, 9–10 놓치면 안 됨. 이유 한 줄.
   - 화면: **반원 게이지(우리 지수)** — 색: 옅은 초록 → 진한 초록 → 초록 위 붉은빛 → 진홍(강할수록 빨강). Kp·G등급은 작게 참고. 오늘 밤 판정, 세 조건(활동·구름·어둠/달), **시간대별 막대(오로라 커튼 색: 약하면 옅은 초록, 길수록 진한 초록 + 위쪽 붉은 띠, 아주 강하면 아래 끝 분홍)** + 달 높이 곡선 + 위상 아이콘, 범위는 도시의 실제 어두운 시간, 「완전히 어두운 시간 N시간」, 백야면 「시즌 아님 · ○월 ○일경부터」. 실시간 태양풍(속도·Bz), 3일 Kp, 27일 전망, 위상 달력(신월 주간, 어둠 시간, 춘·추분 활동 잦은 시기), 더 맑은 곳 찾기, 촬영 설정 참고, 오로라 지도(OVATION 띠 + 구름 + 남쪽 한계선).
   - 국내: 평소 한 줄, Kp 8+ 때만 「카메라로 붉은 오로라 가능」 안내.
   - 「강해지면 알림」(웹 푸시): **만들어 두고 꺼 둠**(스위치 `aurora_alert`, 함수 미배포).
   - 검증: 지수·구성요소 시간별 기록 저장(오늘부터), 자력계(FMI 등) 수집, 전천 카메라 분석은 자료 확인 후. 「봤다/못 봤다」 버튼은 만들어 두고 꺼 둠.
7. **드론**: 지도 점 → 비행금지(P)/제한(R)/관제권(9.3km)/150m 이상, **비행 승인과 국방부 촬영 허가를 따로 표시**, 「비행 가능」 단정 금지(최선: 「알려진 제한구역 아님」), 공식 링크(드론 원스톱). 나라별 규정(한국·일본·노르웨이·아이슬란드·핀란드·캐나다·미국부터): 무게별 등록·자격, 외국인 절차, 고도·야간·사람 위, 국립공원, 공식 링크, **마지막 확인 날짜**(공식 자료로만 작성). 드론 비행 날씨(고도별 바람·돌풍·비·시정·기온).
8. **화산·지진**: 지진은 **예보 불가 → 실시간 발생·해일 경보**(기상청 지진정보, USGS, JMA). 등록 도시 근처 일정 규모 이상이면 띠 표시. 화산: 공식 경보 단계, 분화 상태, 통제 구역·공식 관람 지점, 가스 확산 예보(아이슬란드 기상청), 화산재 항공 영향. 「안전」 판단 금지, 출처·발표 시각, 오래된 자료 표시.

## 5. 지도
- 국내 **카카오**(지도 + 장소 검색 + 로드뷰), 해외 **MapTiler**. 위치에 따라 자동 전환. 각 지도 결과는 그 지도에서만 사용. 계산은 지도와 무관(sky-core).
- 장소 검색: 국내 카카오 로컬(서버 함수 `places`, `KAKAO_REST_KEY`, 캐시·호출 제한), 해외 MapTiler 지오코딩.
- 키 없을 때: 지도 자리는 안내 문구, 계산 기능은 좌표 직접 입력으로 동작.
